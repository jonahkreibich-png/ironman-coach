# Für Jonah

**Neues Icon aufs iPhone holen** (das iPhone tauscht es nicht von selbst):
1. In **Safari** https://coach-app-efc7.pages.dev öffnen → Teilen → **Zum Home-Bildschirm**.
2. In der **alten** App: Mehr → Konto → „Gerät hinzufügen“. Es erscheint ein Code.
3. Die **neue** App öffnen: unter „Schon dabei?“ den Code eingeben.
4. Wenn in der neuen App deine Daten da sind: altes Icon löschen.

**Mitteilungen einschalten** (in der neuen App): Mehr → Einstellungen → Mitteilungen → „Mitteilungen erlauben“ → im iPhone-Fenster „Erlauben“. Mit „Test senden“ prüfen.
