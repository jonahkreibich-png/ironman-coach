# Beispiel-.fit-Dateien für Tests

Echte .fit-Dateien von verschiedenen Uhren und Radcomputern (Garmin Fenix, Edge, COROS, Multisport) aus dem
Open-Source-Projekt [python-fitparse](https://github.com/dtcooper/python-fitparse) (MIT-Lizenz, siehe
`LICENSE-python-fitparse.txt`). Die `*-records.csv` sind die dort mitgelieferten Referenzwerte.
Sie enthalten keine Daten aus dieser App. Zusätzlich erzeugt `tests/unit/fit.test.ts` eigene Dateien
(Schwimmen mit Bahnen, Intervalle), weil HealthFit-Dateien von Jonah erst nach der Einrichtung kommen.
